As of now, this scanner runs on 2000 threads..which can be changed from  port_scan.rs .
It contains of two modes.Fast and full. 
Fast scans first 1000 ports along with some most common ports though they are above 1000
Full scan scans all the 65535 ports

### HOW TO USE
- Go to main folder directory i.e `/rusty_ports`
- do `cargo run`
